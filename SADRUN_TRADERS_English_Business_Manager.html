Bulk Item Import

Upload a spreadsheet or document to prepare multiple stock items

Upload Item List

For reliable bulk import, use a CSV file with columns: name, sku, cost, price, stock, gst. You can also upload a JSON backup exported from this app.

PDF and image files can be selected and previewed here, but automatic OCR extraction is not enabled in this offline starter. Review and enter extracted details before saving. Do not import unverified quantities or prices.

CSV Format Example

name,sku,cost,price,stock,gst
Urea 45kg,UREA45,260,270,100,5
